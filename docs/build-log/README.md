# Build log

One file per session, named `YYYY-MM-DD-session-name.md`. It takes five minutes, and it turns a pile of commands into a record that someone else can learn from.

**Before you commit:** check the file has no account numbers, secrets or private URLs. Replace them with placeholders like `123456789012`.

## Template

```markdown
# <Thursday date>: <title>

Date:
Time spent:
Course lessons watched:

## What I built
One or two sentences.

## What broke
The exact error message, pasted.

## How I found the cause
What I tried, in order, including the dead ends.

## The fix
What actually worked.

## What I learned
One thing I could explain to someone else.

## Evidence
A screenshot, a command output, or a link to the commit.

## Status
Tested on <date> / Draft
```
